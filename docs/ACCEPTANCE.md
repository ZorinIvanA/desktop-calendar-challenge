## Что осталось проверить на Windows-машине

1. Все 5 пунктов Windows-чек-листа выше (особенно per-monitor `SetWallpaper`).
2. `Microsoft.Win32.Registry` доступен без NuGet-пакета на net8.0-windows.
3. COM `IDesktopWallpaper` vtable — вызовы не падают (порядок методов исправлен в M4 по
   данным исследования, но требует подтверждения на реальной Windows).
4. DPI-scaling на HiDPI-мониторах (на 96-dpi Linux-машине scaling=1.0).

## Известные ограничения

- **GNOME per-screen:** единый URI обоев на сессию — календарь применяется к общему фону,
  координатно привязан к выбранному монитору (TZ §2.2).
- **KDE/XFCE** не поддерживаются (только GNOME). Контракт `IWallpaperService` позволяет
  добавить backend'ы без правок ядра (TZ §10).
- **Авторан при `dotnet run`** указывает на `dotnet`-хост — корректно только после
  `dotnet publish` (см. [`AUTORUN.md`](./AUTORUN.md)).
- **Ежедневное обновление без GUI/логина** требует системного планировщика (cron/Task-Scheduler) —
  встроенный таймер работает только при открытом окне.
